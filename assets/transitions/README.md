# Héroïne — transitions des six manches

Six variantes créées le 17 novembre 2026 avec l’outil de génération d’images, à partir de l’héroïne existante dans `assets/Le grand voyage gourmand à Coutras.png`. Cette référence reste intacte. La première variante a également servi de référence de cohérence aux cinq suivantes.

Les fichiers sont séparés pour permettre leur remplacement sans changer le composant. Les PNG conservent leur transparence et sont affichés entiers, sans recadrage. Un seul fichier est chargé par présentation.

| Fichier | Accessoire |
| --- | --- |
| `01-carte-locale.png` | Carte routière locale |
| `02-cuisine.png` | Tablier et cuillère de cuisine |
| `03-commandes.png` | Carnet de commandes et crayon |
| `04-gps-envers.png` | GPS à l’envers, expression perplexe |
| `05-carte-identite.png` | Carte d’identité au format carte, pas un passeport |
| `06-tour-du-monde.png` | Globe et valise |

Les variantes reprennent le visage, la coiffure brune relevée, les boucles d’oreilles, le tee-shirt clair, le tablier bleu et le style illustré de l’héroïne d’origine. Les titres et dialogues sont du texte HTML dans le composant ; ils ne sont pas incrustés dans les images.
